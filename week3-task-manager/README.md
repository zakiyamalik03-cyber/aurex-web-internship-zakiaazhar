# Week 3: JavaScript Task Manager (Part 1)

A simple task manager built with HTML, CSS and vanilla JavaScript.

## Features
- Add a task
- Show the list of tasks
- Delete a task
- Mark a task as completed
- Basic input validation (empty, too short, too long, duplicate)

## Files
- `index.html`: page structure
- `style.css`: styling
- `script.js`: task manager logic
- `exercises.js`: JavaScript practice exercises (conditions, loops, functions, arrays, objects, ES6)

## How to Run
Open `index.html` in a browser. Run the exercises with `node exercises.js`.

## Note
Tasks are stored in memory only, so they disappear when the page is refreshed. localStorage will be added in Week 4.
