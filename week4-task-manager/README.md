# Week 4: JavaScript Task Management Application

A task management application built with only HTML5, CSS3, vanilla JavaScript, the DOM and localStorage.

## Features
- Add a task
- Edit a task
- Delete a task
- Mark a task as completed
- Filter tasks: All, Active, Completed
- Form and input validation (empty, too short, too long, duplicate)
- Tasks are saved in localStorage and are still there after refreshing the page
- Remove completed tasks (updates the stored data)
- Responsive layout for desktop, tablet and mobile

## Files
- `index.html`: page structure
- `style.css`: styling and responsive layout
- `script.js`: application logic and localStorage

## How to Run
Open `index.html` in a browser.

## What I Learned
- Selecting and changing elements with the DOM
- Handling click, submit and change events
- Validating form input and showing messages
- Saving and reading data with localStorage, JSON.stringify() and JSON.parse()
